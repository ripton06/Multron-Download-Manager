# Issue tracker

The proposals are tracked in https://github.com/Multron-Community/Multron-Download-Manager/issues.
Read an issue and its discussion with `gh issue view NUMBER --repo Multron-Community/Multron-Download-Manager --comments`.

Original requests: #50 (tracker search), #51 (protected browser sessions), #52 (system-player playback), #53 (extension torrent actions), #54 (appearance).
The implemented first-stage scope is defined in `docs/FORK_IMPLEMENTATION.md`; it is narrower than the five original proposals.

Work is being developed in the user's personal fork, https://github.com/ripton06/Multron-Download-Manager. Publishing comments to the upstream tracker needs a direct instruction from the user.
